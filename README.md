# SQL Portfolio — Supply Chain & Facilities Analytics

A collection of sanitized, production-derived SQL demonstrating real
analytics engineering work: multi-source data consolidation, incremental
warehouse pipelines, and business-rule encoding at scale.

**Every table, schema, and column name below has been renamed or
genericized.** No proprietary identifiers, vendor names, or internal
system names survive from the original production code. What's
preserved is the actual logic, structure, and complexity of the work —
these are real problems solved with real SQL, not toy examples written
for a portfolio.

Each project below ships as two files:
- **Full version** — the complete, unabridged pipeline exactly as it
  runs in production (renamed).
- **`_Summary` version** — a condensed excerpt built for readability,
  pulling out the 3-4 most portfolio-relevant techniques from the full
  file with inline comments explaining what each block demonstrates.

Start with the summaries if you're skimming; read the full versions for
the real scope and edge-case handling.
